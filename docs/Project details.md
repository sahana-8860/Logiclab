Blood Donor Finder Application

Project Title

Blood Donor Finder Application Using Python, Flask, and SQLite

Abstract

Blood is a vital resource required during medical emergencies, surgeries, and treatments. Finding suitable blood donors quickly can be difficult, especially during urgent situations. The Blood Donor Finder Application is a web-based system designed to connect blood donors with recipients efficiently.

The application allows donors to register their details, including blood group, contact information, and location. Users can search for available donors based on blood group and location. The system stores donor information in a database and provides quick access to matching donors during emergencies.

This project aims to simplify the blood donation process, reduce search time, and help save lives through effective donor management.

Objectives

- To maintain donor information digitally.
- To search donors based on blood group and location.
- To reduce the time required to find blood donors.
- To provide a simple and user-friendly interface.
- To support emergency blood requests.
